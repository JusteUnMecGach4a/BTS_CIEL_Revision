# Instructions pour l'IA (Antigravity)

À chaque intervention sur ce projet, tu dois impérativement suivre ces règles :

1. **Mise en ligne** : Effectue une mise à jour du site sur GitHub (`git push`) après chaque modification majeure ou demande de l'utilisateur.
2. **README** : Mets à jour le fichier `README.md` pour refléter les derniers changements, les nouvelles pages ou les nouvelles fonctionnalités.
3. **Questions** : Si une instruction est ambiguë ou si tu as un doute sur le design ou le contenu, pose-moi la question avant d'exécuter.
4. **Style** : Conserve l'esthétique Cyberpunk/Neon (Tailwind, Orbitron, Glassmorphism) pour toutes les nouvelles pages.
5. **MathJax** : Utilise MathJax pour toutes les formules mathématiques ou physiques.
