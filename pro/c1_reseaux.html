Réseaux Informatiques

01 Modèles & Protocoles

Modèle OSI vs TCP/IP

L'OSI (7 couches) est théorique, le TCP/IP (4 couches) est le standard d'implémentation réel d'Internet.

Protocoles Clés

IP TCP/UDP DNS HTTP ARP

02 Adressage & Routage

Calcul de Sous-Réseaux

Utilisation de la notation CIDR (ex: /24). Calcul des masques, adresses réseau et broadcast.

Ex: 192.168.1.0/24 -> Masque: 255.255.255.0 | 254 hôtes disponibles

Équipements

Switch (L2) vs Routeur (L3). Fonctionnement des tables MAC et tables de routage.

NAT

Network Address Translation : Permet à plusieurs machines privées de sortir via une seule IP publique.

03 Diagnostic Réseau

Ligne de Commande

  • • ip addr Voir les interfaces
  • • ping Tester la connectivité
  • • nmap Scanner les ports
  • • nslookup Résolution DNS

Wireshark

Analyseur de protocoles (Sniffer). Permet de capturer les trames et d'analyser le contenu des paquets (headers, payload).
